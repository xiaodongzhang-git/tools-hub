Text Notes

Saved Notes

    How to Use

    This page provides a simple online text editor with automatic saving in your browser. Notes are stored locally using your browser storage and are not uploaded to any server.

    Create and edit notes

    1. Click + New Note on the left to create a blank note.
    2. Start typing in the main editor area. The first non-empty line will be used as the default title.
    3. You can manually edit the title in the top text field at any time. Changes are saved automatically.

    Import and export TXT files

    1. Click Upload TXT to import a .txt file as a new note.
    2. The file name will be used as the note title and the file content as the body.
    3. Click Download TXT to export the current note as a plain text file.

    Technical notes

    Text notes are stored using the browser's localStorage API. Your notes are kept only on your device and are never transmitted to a remote server. Clearing your browser data or using a different browser or device will remove or separate your saved notes.
