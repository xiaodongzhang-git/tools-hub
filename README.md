# Tools Hub

A static, browser-based tools website for developer utilities and AI productivity workflows.

## Core tools

- JSON Formatter
- JSON to CSV / CSV to JSON
- JSON Diff
- AI Prompt Generator
- AI Token & Cost Estimator
- SEO Meta Tag Generator
- UTM Builder
- Image Compressor
- Base64 text converter
- Image to Base64 converter
- URL encoder / decoder
- JWT decoder
- UUID generator
- Text counter
- Local notes

All tools run in the browser with plain HTML, CSS, and JavaScript.
